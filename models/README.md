# Nova local models

Place one instruct-tuned GGUF model here and name it:

`nova-assistant.gguf`

Recommended Pi 5 envelope:

- 1B–1.5B parameters, Q4 quantization: fastest practical everyday choice
- 3B parameters, Q4 quantization: better answers, slower, best with 8–16 GB RAM

Model weights are intentionally excluded from Git. Check the model card and
license before downloading or redistributing any weights.
