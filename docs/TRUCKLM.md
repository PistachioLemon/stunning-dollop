# RequantAi TruckLM

The CPU baseline uses deterministic rules and works without a model. An optional small quantized GGUF can run through llama.cpp for trucking language, classification, structured output, and tool selection. Model output remains advisory until the Permission Broker authorizes a named action.

Changing regulations and operating data belong in cited retrieval packs rather than model weights. Training batches require acknowledgement for the 1:00 AM Pacific window and candidates never auto-promote.

## Hardware policy

- Required baseline: Raspberry Pi 5 CPU, storage, and simulation adapters.
- Optional: GPS, CAN/OBD, reefer, load sensors, MQTT, and truck/cargo cameras.
- Optional acceleration: Hailo or Coral, detected at runtime. Absence must never prevent startup.
